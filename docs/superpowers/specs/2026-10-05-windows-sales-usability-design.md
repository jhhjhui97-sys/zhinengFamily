# Windows 离线版销售操作改进设计

## 目标与约束

门店销售员要能清理误建客户，在 3D 房间内直接调整家具，并在没有 GLB 时用商品照片和真实尺寸得到可摆放的模型。所有操作在本机完成，保留现有 SQLite、SceneModel、商品资产版本和报价快照。用户已授权在软件落地前选择可行方案；本设计按可恢复性和尺寸可靠性优先。

## 客户移出与恢复

客户列表增加“移出客户”操作和“已移出客户”入口。移出为软删除：新增 `deleted_at` 字段并进行 v7 数据库迁移，默认列表隐藏，关联项目、场景、报价及订单不删除。操作前明确提示关联资料会一并从常规列表隐藏；必须确认且带客户修订号，避免并发误操作。已移出列表可恢复客户及原有全部关联资料。后台读取项目或场景时拒绝已移出客户，恢复后重新可用。手机号唯一约束只作用于有效客户；若已移出客户的手机号被新客户使用，恢复时显示冲突并保留原资料。迁移前自动备份，旧库原有客户默认为有效。

## 3D 家具直接操控

点击家具模型选中并同步右栏“当前家具”。按住中键拖动选中家具沿所在楼层水平移动；按住右键水平拖动按角度旋转。左键空白处仍旋转视角，滚轮仍缩放。拖动时显示与最近墙面的距离及坐标，接近墙面时提示可对齐；在释放鼠标时校验房间边界与已有家具碰撞，非法位置保留原姿态并给出中文原因。成功调整只修改草稿，仍需显式保存新版本；历史版本保持不可变。数值输入与鼠标操作共用同一校验规则。

## 图片和尺寸生成近似模型

商品详情增加 JPEG/PNG 图片上传及“生成近似 3D 模型”。已保存商品的宽、深、高是最终尺寸；本机生成有体积的 GLB 近似几何，并把图片嵌入可见正面。首版针对沙发、床、桌、冰箱、洗衣机提供简单类别外形；其他类别使用带贴图的尺寸盒。生成的 GLB 走现有模型校验、资产附加和版本固定流程，不引入云端模型、外部 API 或授权不清的依赖。界面明确标为“尺寸近似模型”，不宣称单张图片还原背面、材质或工程结构。无效图片、尺寸、超大文件应拒绝且保留旧模型。

## 验证

本地 C# 存储测试覆盖迁移、删除/恢复、并发冲突、关联资料可用性；浏览器测试覆盖完整客户操作、家具鼠标交互及图片生成后的摆放与重启持久化；纯逻辑测试覆盖房间边界、碰撞和模型结构。Windows CI 必须验证真实 SQLite 桥接和便携包。白屏另行按故障证据处理，不把这三项功能通过等同于用户机器上的启动问题已解决。
