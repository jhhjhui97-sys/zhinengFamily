# Windows 离线 DXF 户型导入设计

日期：2026-10-05。基线：`codex/windows-offline-room-materials`。本阶段只扩展 Windows 本地客户端；客户、项目、商品和场景版本仍保存在本机，不依赖云端。

## 目标与验收

销售员在已选择的客户项目中创建方案，选择一个二维 DXF，确认房间轮廓图层和可选的墙线图层，核对单位或用一段已知长度校准。应用显示二维预览及识别数量，将可信的房间和墙体转换成现有 `SceneModel` 草稿，经过原有 C# 校验后在 3D 中显示。销售员确认并保存时仍使用现有乐观锁与不可变场景版本。原始 DXF 保留在 `%LOCALAPPDATA%/ZhinengFamily/floorplans`，随整个资料目录备份。

验收使用至少两份可重现 DXF：一份含明确毫米单位、多个房间和独立墙线图层；一份无可靠单位，需要按已知线长校准。浏览器测试必须覆盖真实选择文件、预览、校准、导入、保存和重开。错误文件、危险或过大输入、缺少闭合轮廓、无效比例和校验失败不能改变当前已保存场景。

## 可行性选择

1. **采用 Node 侧 DXF 解析器，加隔离 worker。** Windows 便携版已经捆绑 Node，`dxf-parser` 采用 MIT 许可并支持常见二维实体与图层；解析只在本机进行。worker 设置时间和实体数量上限，主服务只接收受限的结果。
2. C# 解析器与现有桥接同语言，但需要验证额外 .NET 依赖在 .NET Framework 4.8 便携包中的兼容性，增加当前交付风险。
3. Python `ezdxf` 功能更广，但便携包需新增 Python 运行时及依赖，体积和更新复杂度更高。

解析器通过 `DxfParser` 适配器调用，场景转换不直接依赖它的对象形状。以后可替换解析器或增加 DWG 转换器。只引入许可允许闭源分发的依赖，保留许可证。

## 本阶段可识别的内容

- 读取 ASCII/UTF-8 文本 DXF 中 modelspace 的 `LINE`、直线段 `LWPOLYLINE` 和 `POLYLINE`，保留图层、线段端点、闭合状态和 `$INSUNITS`。圆弧 bulge、样条、块插入、三维实体和外部参照暂不转成场景；界面报告跳过数量。不能把跳过的门窗、梁柱或水电点位说成已识别。
- 用户必须选择一个含闭合多边形的房间轮廓图层。每个合格闭合轮廓生成一个 Room。可另选墙体中心线图层生成 Walls；未选时按房间边界生成墙中心线，并对相同边去重。房间名按序号生成，可在后续编辑。墙厚默认 200 mm、层高默认 2800 mm，界面明确标注为估算值。
- `$INSUNITS` 为毫米、厘米或米时显示换算建议，仍由用户确认；为 0、缺失或其他值时必须校准。校准由用户在预览中选择一条直线并输入实际毫米长度，换算系数为 `实际毫米长度 / DXF 线长`。空值、零长、非有限或超出合理范围的比例一律拒绝。
- 统一转换为 mm、右手 XY 平面、Z 向上。将平面几何平移到场景原点附近，并在 metadata 记录源坐标偏移、校准系数和源文件 SHA-256。闭合轮廓方向规范成逆时针；自交、重复点等不隐式修复，交给现有完整 SceneModel 校验并显示可理解的失败原因。

## 本地数据流与安全

浏览器只向本机同源 `/api/dxf/analyze` 上传最大 8 MiB 的 DXF 原始字节。该路由沿用 Host、Origin 和 HttpOnly 本地会话检查，并限制总读取时间；只接受 `.dxf` 和文本 DXF，拒绝 DWG、二进制 DXF、无效编码及明显异常实体数量。解析在 worker 中完成，超时即终止，绝不执行 DXF 中的链接、脚本或外部参照。响应只包含转换所需的受限图元、图层、单位和跳过统计，不回传原始文件文本。

用户确认导入时，同一文件再次发送到 `/api/dxf/archive`；服务端按 SHA-256 命名并原子写入资料目录，拒绝客户端路径。浏览器根据已解析图元及用户选择建立草稿，使用原有 `validate` 动作校验后才替换当前草稿。保存仍由现有 `save` 动作负责。若归档、转换或校验失败，原场景和未保存编辑保持不变。归档的源文件是本地备份材料，不提供网络下载地址。

## 界面与错误

导入入口放在项目方案的“载入两室一厅”旁，仅在已有方案时可用。选择文件后显示二维预览、图层列表、当前单位建议、房间数、线段数和未支持实体数。点击预览线段可选择校准基准；输入实长后显示比例。用户点击“生成 3D 草稿”前可检查墙层和默认厚度/高度。导入成功后显示原始文件名及估算提示；必须由用户手动保存版本。离开或覆盖未保存草稿沿用当前确认提示。

常见失败给出中文说明：文件格式不支持、文件过大、无可用房间、单位未确认、长度校准无效、几何不符合 SceneModel、解析超时。错误消息不包含本地绝对路径或 DXF 原文。

## 明确限制与后续

首版不承诺任意 CAD 自动成屋；不自动识别门窗、梁柱、水电、楼层或厚度，也不支持 DWG、PDF、AI 布局。真实图纸若只有双线墙、没有闭合房间轮廓，需要销售员先在 CAD 软件中整理轮廓或等待后续人工描绘功能。此限制必须在导入界面和 README 中写明。测试通过只说明覆盖样例与边界，不等于所有设计院 DXF 都能直接导入。
